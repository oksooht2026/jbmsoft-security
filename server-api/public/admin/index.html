설치 · 테스트 가이드

1. 서버 배포 (최초 1회) API 서버를 Vercel에 배포합니다.
cd server-api && vercel --prod
DB 설정 동기화: node update_db.js
2. 클라이언트 설치 PowerShell을 관리자 권한으로 실행 후:
npm install → npm start (개발 테스트)
배포용 설치 파일: npm run build → dist/OksooSecurity_Setup.exe
3. 관리자 패널 브라우저에서 admin-panel/index.html 열기 (또는 Vercel 배포 URL)
마스터 비밀번호 로그인 → 글로벌 정책에서 USB·메일·확장자 설정 후 저장
4. 기능 테스트
  • USB — USB 꽂기 → 차단 → 대시보드 승인 → 30분 사용 허용
  • 파일 — 차단 확장자(pdf 등) 파일 복사 → 격리 → 승인 → 복원
  • 메일 — Outlook 등으로 발송 시도 → 차단 → 승인 → 30분 허용
  • 웹메일 — mail.naver.com 등 hosts 차단 (브라우저 접속 불가)
5. 확인 포인트 클라이언트 관리자 승인 탭 · 이 패널 관제 대시보드에서 요청 확인
PC 온라인 표시: 5분 이내 하트비트 (정책 변경 시에만 전체 정책 수신)
