프로그램 · 관리자 패널 사용법

📦 PC 보안 프로그램 (직원용)

설치 관리자가 배포한 OksooSecurity_Setup.exe를 실행해 설치합니다. 설치 후 PC 재부팅 시 트레이(시계 옆)에 아이콘이 표시되면 정상입니다.
일상 사용 직원은 별도 설정 없이 프로그램을 켜 두기만 하면 됩니다. 창을 닫아도 트레이에서 보안이 계속 동작합니다.
차단 시 알림 USB 연결, 메일 발송, 차단 확장자 파일 이동 등이 차단되면 화면 오른쪽 아래에 알림이 뜹니다. 「관리자에게 승인을 요청했습니다」 안내 후, 관리자 승인까지 대기합니다.
일시 중지 / 종료 트레이 아이콘 우클릭 → 「일시 중지」는 관리자 비밀번호 필요, 「종료」도 관리자 인증 후 가능합니다. 일시 중지 시 USB·메일 차단이 해제됩니다.

🖥 관리자 패널 (관리자용)

로그인 공식 주소에서 마스터 비밀번호로 로그인합니다. 로그인 후 왼쪽 메뉴로 기능을 이동합니다.
관제 대시보드 온라인 PC 수, 오늘 차단 건수, 승인 대기 건수를 확인합니다. USB·메일·파일 승인 요청은 표에서 바로 「승인」 또는 「거부」할 수 있습니다.
결재 / 승인함 모든 승인 요청 내역을 유형(🔌 USB / 📧 메일 / 📄 파일)별로 확인하고 처리합니다. 승인 후 PC에 약 1~2분 이내 반영되며, USB·메일은 30분간 허용됩니다.
글로벌 정책 클립보드·파일 감시·메일·USB 차단 ON/OFF, 차단 확장자, 유해 사이트 목록을 설정하고 「정책 저장 및 배포」를 누르면 전체 PC에 5분 이내 반영됩니다.
라이선스 등록된 PC 수와 한도(기본 42대)를 확인합니다. 한도 변경은 별도 인증 비밀번호가 필요합니다.
