USB 차단/승인 및 프로그램 제거 프로세스 관련 최종 수정본을 송부해 드립니다. 

아래 사항들을 중점적으로 조치 및 개선 완료하였습니다.

1. NAS 및 네트워크 드라이브 오탐/차단 제외 처리
* 실제 USB가 아닌 가상/네트워크 NAS 드라이브(Z:, Y:, T: 등)가 USB 차단 정책 활성화 시에도 정상 마운트되고 오탐 없이 확실하게 차단 대상에서 제외되도록 예외 처리 로직을 전면 보완하였습니다.

2. 프로그램 제거 시 비밀번호 인증창 추가 및 버그 수정
* Windows 보안 정책(UAC 관리자 세션 격리)으로 인해 제거 시 비밀번호 입력창이 노출되지 않던 현상을 해결하기 위해, VBScript 기반의 최상위(TopMost) InputBox 인증 다이얼로그 방식으로 전면 교체하여 제어판 제거 시 비밀번호 입력창이 안정적으로 팝업되도록 개선했습니다.
* 설치 프로세스 중 잔재 플래그로 인해 수동 제거 시 비밀번호 검증 단계를 무시하고 넘어가던 버그 또한 수정하여 상시 마스터 비밀번호가 요구되도록 조치했습니다.

3. 프로그램 제거 및 강제 종료 시 USB 드라이브 자동 복구 보강
* 프로그램이 지워지거나 강제 종료될 때, 차단되었던 USB가 윈도우 탐색기('내 PC')에서 영구적으로 사라지던 마운트 유실 현상을 방지하도록 안전장치를 보강했습니다.
* 드라이브 차단 시 로컬 레지스트리에 백업 영역을 추가하고, 언인스톨러 실행 및 재설치 시 해당 정보를 조회하여 기존에 갇혀 있던 USB 드라이브 문자를 윈도우 시스템에 완전히 자동 복구하도록 조치했습니다.

4. 관리자 웹 승인 반영 지연 버그 수정 (서버 패치 완료)
* 기기 동기화 시 서버 DB의 스키마 및 정렬 쿼리 오류로 인해 승인 내역이 항상 빈 값으로 응답되던 버그를 패치하여 상용 API 서버(Vercel)에 반영 완료하였습니다. 이제 관리자 웹에서 승인을 누르면 에이전트에 실시간(5~10초 내)으로 바로 반영됩니다.

5. 클립보드 개인정보 보호 정책 기본값 변경 및 관리자 연동
* 프로그램 초기 구동 시 불편을 줄이기 위해 클립보드 차단 기능의 기본 시작 값을 OFF로 변경하였으며, 관리자 웹의 글로벌 정책 설정에서 클립보드 감시 여부를 실시간으로 켜고 끄실 수 있도록 양방향 연동을 완료하였습니다.

6. 백신 프로그램(안랩 V3 등) 호스트(hosts) 파일 변조 오탐지 안내
* 발생 원인: 프로그램 정책 중 '비인가 웹사이트/웹메일 접속 차단' 기능을 수행하기 위해, 윈도우 시스템의 호스트 파일(C:\Windows\System32\drivers\etc\hosts)에 차단 도메인을 추가하는 동작이 일어납니다. 일부 백신(V3 등)에서 이를 파밍 방지 목적의 악성 변조 시도로 감지하여 차단 알림을 띄우는 오탐지가 발생할 수 있습니다.
* 해결 방법: 안랩 V3의 개인 방화벽/네트워크 보안 설정에서 OksooSecurity.exe 프로그램 혹은 설치 폴더 전체를 검사 예외(신뢰 프로그램) 대상으로 등록해 주시거나, 호스트 변조 알림 창이 떴을 때 '허용' 혹은 '예외 처리'를 적용하고 실행해 주시면 문제없이 정상 작동합니다.
